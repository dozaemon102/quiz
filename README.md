# Quiz App

ローカル専用の資格対策クイズアプリです。CSVファイルで問題を管理し、Flaskで動作するWebアプリです。

---

## 機能

- **複数CSVに対応** — `problems/` フォルダに複数の問題CSVを配置し、画面から切り替えて使用できます
- **分野フィルタ・問題数選択** — 出題条件（分野・問題数）を絞り込んでクイズを開始できます
- **復習モード** — 過去に間違えた問題だけを出題します
- **統計画面** — 総回答数・正答率・分野別成績を確認できます
- **間違った問題** — ミス回数の多い問題を一覧表示します（直近の誤答も確認可）
- **学習進捗画面** — CSV全体および分野別の問題消化率をパーセントで確認できます
- **キーボード操作** — `1`〜`4` キーで選択肢を選び、`Enter` キーで回答・次の問題へ進めます

## セットアップ

### 必要環境

- Python 3.8 以上
- uv

### インストール

```bash
uv sync
```

### 起動

```bash
uv run python app.py
```

ブラウザで `http://127.0.0.1:5000` にアクセスしてください。

初回起動時に `quiz.db`（SQLiteデータベース）が自動生成されます。

## 問題CSVの形式

`problems/` フォルダに以下の形式のCSVを配置してください。

| 列名 | 説明 |
|------|------|
| `No` または `No.` | 問題番号（必須・一意） |
| `問題文` または `問題` | 問題文 |
| `選択肢A` | 選択肢A |
| `選択肢B` | 選択肢B |
| `選択肢C` | 選択肢C |
| `選択肢D` | 選択肢D |
| `正解` | 正解の選択肢記号（`A` / `B` / `C` / `D`） |
| `解説` | 解説文（任意） |
| `分野` | 分野名（フィルタに使用） |

**CSVの文字コードは `UTF-8`（BOM付き `UTF-8-sig` も可）に対応しています。**

### サンプル

```csv
No,分野,問題文,選択肢A,選択肢B,選択肢C,選択肢D,正解,解説
1,ネットワーク,IPアドレスのクラスAの範囲はどれか,0.0.0.0〜127.255.255.255,128.0.0.0〜191.255.255.255,192.0.0.0〜223.255.255.255,224.0.0.0〜239.255.255.255,A,クラスAは先頭ビットが0のアドレス範囲です。
```

## キーボードショートカット

| キー | 動作 |
|------|------|
| `1` / `2` / `3` / `4` | 選択肢を選ぶ |
| `Enter` | 回答送信 / 次の問題へ |

## データ管理

回答履歴は `quiz.db`（SQLite）に保存されます。履歴を完全にリセットしたい場合は、アプリ画面の「履歴クリア」リンクから削除するか、`quiz.db` ファイルを直接削除してください。
